## Conversor de Monedas

# Aplicación desarrollada en Java que permite convertir valores entre distintas monedas utilizando información obtenida desde una API de indicadores económicos. El proyecto consume servicios REST, procesa respuestas en formato JSON y utiliza tasas de cambio actualizadas para realizar conversiones de forma rápida y precisa.

## Características: 

- Consumo de API REST.
- Procesamiento de datos JSON.
- Conversión entre monedas internacionales.
- Consulta de indicadores económicos como dólar y euro.
- Interfaz de consola interactiva.
- Implementación de buenas prácticas de Programación Orientada a Objetos (POO).

## Tecnologías utilizadas:

- Java
- Gson
- API HTTP
- JSON
